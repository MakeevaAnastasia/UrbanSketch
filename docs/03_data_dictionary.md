# 03. Словарь входных данных
**Источник:** исходное ТЗ; различия строительных и реализуемых площадей сохранены.

## Технико-экономические показатели (ТЭП)
| Показатель | Поле | Единицы | Примечание |
|---|---|---|---|
| Жилая площадь | residentialSaleAreaM2 | м² | реализуемая для выручки |
| Коммерческая площадь | commercialSaleAreaM2 | м² | реализуемая для выручки |
| Количество жителей | population | чел. | информационный ТЭП |
| Количество машино-мест | parkingSpaces | шт. | источник количества, способ разделить продаваемые/строящиеся уточнить |
| Количество зданий | buildingsCount | шт. | информационный ТЭП |
| Максимальная этажность | maxStoreys | этаж | информационный ТЭП |
| Социальные площадки | socialAreaM2 | м² | учёт расходов уточнить |
| Количество мест в ДОУ | kindergartenPlaces | мест | при наличии |
| Количество мест в СОУ | schoolPlaces | мест | при наличии |

## Дополнительные площади
- `residentialConstructionAreaM2` — площадь для расчёта стоимости строительства жилья, м².
- `commercialConstructionAreaM2` — площадь для расчёта стоимости строительства коммерции, м².
- Если отсутствуют, ТЗ требует ручной ввод **или** расчёт по коэффициенту, задаваемому пользователем. Коэффициент и алгоритм согласовать.

## Редактируемые финансовые параметры
| Поле | Назначение | Единицы | Пример ТЗ |
|---|---|---|---|
| residentialConstructionCostPerM2 | стоимость строительства жилья | руб./м² | 100 000 |
| commercialConstructionCostPerM2 | стоимость строительства коммерции | руб./м² | 80 000 |
| parkingConstructionCostEach | себестоимость машино-места | руб./шт. | 500 000 |
| residentialSalePricePerM2 | цена продажи жилья | руб./м² | 200 000 |
| commercialSalePricePerM2 | цена продажи коммерции | руб./м² | 150 000 |
| parkingSalePriceEach | цена продажи машино-места | руб./шт. | 1 000 000 |
| landCost | стоимость земли | руб. | 50 000 000 |
| additionalCosts | прочие расходы | руб. | 20 000 000 |
| durationYears | длительность проекта | лет | 3 |

В проектной модели данные хранения денежных сумм используют `numeric(18,2)`, для площадей — `numeric(18,2)`, для годовых долей — `numeric(5,2)` (предложение команды, не обязательный стандарт заказчика).

## Неурегулированные вопросы
- Утверждение валюты (в ТЗ примеры в рублях).
- Разделение количества строящихся и продаваемых парковочных мест.
- Список обязательных полей и значения по умолчанию.
- Можно ли иметь несколько моделей одной концепции.
- Какие нефинансовые ТЭП показывать пользователю, если они не участвуют в расчётах.
