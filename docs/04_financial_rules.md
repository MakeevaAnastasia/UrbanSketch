# 04. Финансовые формулы и правила
**Источник:** исходное ТЗ, разделы 5.3–5.6 и 9. Формулы являются спецификацией для реализации в спринтах 3–4.

## Строительные расходы
1. Жильё = `residentialConstructionAreaM2 × residentialConstructionCostPerM2`.
2. Коммерция = `commercialConstructionAreaM2 × commercialConstructionCostPerM2`.
3. Парковки = `parkingSpacesForConstruction × parkingConstructionCostEach`.
4. Прочие прямые расходы = `landCost + additionalCosts`.
5. **Общие затраты** = сумма четырёх пунктов.

## Выручка
1. Жильё = `residentialSaleAreaM2 × residentialSalePricePerM2`.
2. Коммерция = `commercialSaleAreaM2 × commercialSalePricePerM2`.
3. Парковки = `parkingSpacesForSale × parkingSalePriceEach`.
4. **Общая выручка** = сумма трёх пунктов.

Для MVP по ТЗ продаются **100%** введённых реализуемых площадей и машино-мест; динамическая смена цен и непроданные объекты не учитываются.

## Основные показатели
- **Прибыль** = общая выручка − общие затраты.
- **ROI, %** = прибыль / общие затраты × 100%, если затраты > 0.
- **Рентабельность продаж, %** = прибыль / общая выручка × 100%, если выручка > 0.
- Если знаменатель = 0, показывать **«Не рассчитывается»**, не `Infinity/NaN`.

## Годовые потоки (MVP)
При продолжительности N лет пользователь задаёт долю затрат и долю поступлений каждого года. Сумма долей затрат = **100%**; сумма долей поступлений = **100%**.
- Затраты года = общие затраты × доля затрат года / 100.
- Поступления года = общая выручка × доля выручки года / 100.
- Чистый поток года = поступления − затраты.
- Накопленный поток года = сумма чистых потоков с первого года.

**Точность распределения:** для предотвращения ошибок округления рекомендовано последнему году присваивать разницу между общим итогом и суммой предшествующих округлённых периодов. На согласование.

## Эталонный пример из исходного ТЗ
Вход: жильё 1000 м², коммерция 200 м², парковка 20 мест; цены продажи 200 000/150 000 руб. за м² и 1 000 000 за парковку; строительство 100 000/80 000 руб. за м² и 500 000 за парковку; дополнительные расходы **включая землю** 24 млн руб.; строительные площади условно равны реализуемым.

| Результат | Значение |
|---|---:|
| Выручка: жильё | 200 млн руб. |
| Выручка: коммерция | 30 млн руб. |
| Выручка: парковка | 20 млн руб. |
| **Итого выручка** | **250 млн руб.** |
| **Итого затраты** | **150 млн руб.** |
| **Прибыль** | **100 млн руб.** |
| **ROI** | **66,67%** |
| **Рентабельность продаж** | **40%** |

При затратах 60/40/0% и поступлениях 0/20/80% чистые потоки по годам: **−90 млн; −10 млн; +200 млн**, накопленный итог **+100 млн**.

**Особое уточнение:** тестовые 24 млн уже включают землю. В продуктивном расчёте `landCost` и `additionalCosts` учитываются отдельно; в эталонном примере их сумма = 24 млн, чтобы исключить двойной учёт.

## Точки согласования
- Социальные/инфраструктурные объекты: включить в дополнительные расходы или отдельные категории?
- Если парковка не продаётся, какое число используется в стоимости строительства и выручке?
- Разрешить нулевую продолжительность проекта? Рекомендуем запрещать.
- Фиксировать округление 2 десятичных знака для рублей и денежного результата?
